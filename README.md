# VietinBank NDC Overview BI Report

## Overview

**VietinBank NDC Overview BI Report** is an interactive Power BI report designed to provide an overview of VietinBank's deposit and lending performance.

The report enables users to monitor key business indicators, analyze deposit and loan portfolios, compare performance across different periods, and drill down into customer- and account-level details.

## Report Contents

The report consists of the following main sections:

* **Deposit Overview** – Provides an overview of deposit balances, customers, products, channels, and balance changes.
* **Deposit Change Analysis** – Analyzes changes in deposit balances between selected reporting periods.
* **Deposit Maturity** – Tracks upcoming deposit maturities and related account information.
* **Deposit Detail** – Provides detailed information about deposit customers and accounts.
* **Loan Overview** – Provides an overview of outstanding loan balances, customers, products, and portfolio composition.
* **Loan Maturity / Disbursement** – Monitors upcoming loan-related activities and disbursements.
* **Loan Detail** – Provides detailed information about loan customers and accounts.
* **Customer Detail** – Provides a consolidated view of customer-level deposit and lending activities.

## Key Features

* Interactive date and business-unit filters
* Customer and relationship manager analysis
* Deposit and loan performance monitoring
* Period-over-period comparison
* Top customer increase/decrease analysis
* Deposit maturity monitoring
* Loan disbursement monitoring
* Drill-through to detailed customer and account information
* Interactive charts, tables, and KPI indicators

## Key Metrics

The report includes key metrics such as:

* Deposit Balance
* Loan Outstanding Balance
* Customer Count
* Product Count
* Average Balance
* Balance Change
* Growth Rate
* Deposit Maturity
* Loan Disbursement
* Net Interest Income (NII)

## Purpose

The report is designed to support **management reporting, portfolio monitoring, performance analysis, and customer-level investigation**, providing users with a centralized and interactive view of VietinBank's deposit and lending activities.
